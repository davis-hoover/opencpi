ReStructuredText Code Checker (``ocpi_linter.RstCodeChecker``)
==============================================================
Formatter and code checker for ReStructuredText source code files.

Checking of a file will normally be done by using the command line instruction ``ocpilint``. When a ReStructuredText file is detected this code checker will be used.
