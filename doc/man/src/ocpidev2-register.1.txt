OCPIDEV2-REGISTER(1)
====================


NAME
----
ocpidev2-register - add a project to a project registry.


SYNOPSIS
--------
*`ocpidev2`* ['<options>'] *`register project`*


DESCRIPTION
-----------
The *`register`* verb adds project(s) to the registry.
The default registry
is the one in the OpenCPI installation unless overridden by the
*`OCPI_PROJECT_REGISTRY_DIR`* environment variable.  Registering a
project makes its assets visible and usable to other projects
using the same registry.

Asset types to be specified in the '<noun>' argument are:

*`project`*::
    Register the project.

OPTIONS
-------
The general-purpose options *`-v`* and *`-d`* '<directory>' can be used.
In particular, ecah *`-d`* '<directory>' option can be used to specify
a path to a project being registered.
See the link:opencpi.1.html[opencpi(1)] man page
for descriptions of these general-purpose options.

There are no verb-specific options.

EXAMPLES
--------
. Register the current project
+
----------------------
ocpidev2 register project
