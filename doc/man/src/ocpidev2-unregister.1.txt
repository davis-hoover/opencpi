OCPIDEV2-UNREGISTER(1)
======================


NAME
----
ocpidev2-unregister - remove a project from the project registry.


SYNOPSIS
--------
*`ocpidev2`* ['<options>'] *`unregister project`*


DESCRIPTION
-----------
The *`unregister`* verb removes project(s) from the registry.
The default registry
is the one in the OpenCPI installation unless overridden by the
*`OCPI_PROJECT_REGISTRY_DIR`* environment variable.  Un-registering a
project makes its assets no longer visible or usable to other projects
using the same registry.

Asset types to be specified in the '<noun>' argument are:

*`project`*::
    Unregister the project.

OPTIONS
-------
The general-purpose options *`-d`* '<directory>'
and *`-v`* (*`--verbose`*) can be used.
In particular, the *`-d`* '<directory>' option can be used to specify
the pathname of the project being unregistered.
See the link:opencpi.1.html[opencpi(1)] man page
for descriptions of these general-purpose options.

There are no verb-specific options.

EXAMPLES
--------
. Unregister the current project
+
-------------------------
ocpidev2 unregister project
-------------------------
