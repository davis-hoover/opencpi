OCPIDEV2-SHOW(1)
================


NAME
----
ocpidev2-show - displays information about OpenCPI assets.


SYNOPSIS
--------
*`ocpidev2`*  *`show`* ['<options>'] '<noun>'


DESCRIPTION
-----------
The *`show`* verb is slightly different from other verbs since the command
currently is not associated with a project, but with the operating
environment by default. The registry used is the one in the OpenCPI
installation unless overridden using the *`OCPI_PROJECT_REGISTRY_DIR`*
environment variable.

Asset types to be specified in the '<noun>' argument are:

*`application`*::
    Display information on the specified application.

*`applications`*::
    Display all applications in registered projects.

*`assembly`*::
    Display information on the specified assembly.

*`assemblies`*::
    Display all assemblies in registered projects.

*`card`*::
    Display information on the specified card.
    
*`cards`*::
    Display all cards in registered projects.

*`component`*::
    Display information on the specified component.
    
*`components`*::
    Display all components in registered projects.

*`device`*::
    Display information on the specified device worker.
    
*`devices`*::
    Display all device workers in registered projects.

*`library`*::
    Display information on the specified component library.

*`libraries`*::
    Display all component libraries in registered projects.

*`platform`*::
    Display information on the specified platform.

*`platforms`*::
    Display all platforms in registered projects.

*`primitive`*::
    Display information on the specified primitive.

*`primitives`*::
    Display all primitives in registered projects.

*`project`*::
    Display information on the specified registered project.

*`projects`*::
    Display all registered projects.

*`registry`*::
    Display information on the registry.

*`slot`*::
    Display information on the specified slot.

*`slots`*::
    Display all slots in registered projects.

*`target`*::
    Display information on the specified target that assets can be built for.

*`targets`*::
    Display all targets that assets can be built for.

*`test`*::
    Display all unit tests in registered projects.

*`tests`*::
    Display information on the specified unit test.

*`worker`*::
    Display information on the specified worker.

*`workers`*::
    Display all workers in registered projects.

Use the *`hdl`* keyword to scope what is displayed
for the *`adapter`*, *`adapters`*, *`assembly`*, *`assemblies`*, *`card`*, *`cards`*, *`device`*, *`devices`*, *`library`*, *`libraries`*, *`primitive`*, *`primitives`*, *`platform`*, *`platforms`*, *`slot`*, *`slots`*, *`target`*, *`targets`*, *`worker`*, *`workers`* nouns. For example, the command:

--------------------------
ocpidev show hdl platforms
--------------------------

Use the *`rcc`* keyword to scope what is displayed
for the `*platform`*, *`platforms`* nouns.

OPTIONS
-------
There are no options other then the options common to all OpenCPI tools
(see link:opencpi.1.html[opencpi(1)]),


EXAMPLES
--------
. List all RCC and HDL platforms that assets can be built for:
+
----------------------
ocpidev2 show platforms
----------------------
+
. List all HDL platforms that HDL assets can be built for:
+
--------------------------
ocpidev2 show hdl platforms
--------------------------
+
. List all components in any registered projects
(omits components at the top level of project due to a defect):
+
-----------------------
ocpidev2 show components
-----------------------
+
. Display a table of the registered projects and their locations:
+
-----------------------------
ocpidev2 show --table registry
------------------------------
