OCPIDEV2-SHOW(1)
================


NAME
----
ocpidev2-show - displays information about OpenCPI assets.


SYNOPSIS
--------
*`ocpidev2`*  *`show`* ['<options>'] '<noun>'


DESCRIPTION
-----------
The *`show`* verb is slightly different from other verbs since the command
currently is not associated with a project, but with the operating
environment by default. The registry used is the one in the OpenCPI
installation unless overridden using the *`OCPI_PROJECT_REGISTRY_DIR`*
environment variable.

Asset types to be specified in the '<noun>' argument are:

*`application`*::
    Display information on the specified application.

*`applications`*::
    Display all applications in registered projects.

*`component`*::
    Display information on the specified component.
    
*`components`*::
    Display all components in registered projects.

*`library`*::
    Display information on the specified library.

*`libraries`*::
    Display all libraries in registered projects.

*`project`*::
    Display information on the specified registered project.

*`projects`*::
    Display all registered projects.

*`registry`*::
    Display information on the registry.

*`test`*::
    Display all unit tests in registered projects.

*`tests`*::
    Display information on the specified unit test.

*`worker`*::
    Display information on the specified worker.

*`workers`*::
    Display all workers in registered projects.

Use the keywords *`rcc`* and *`hdl`* to scope what is displayed
for the *`library`* and *`libraries`* nouns. For example, the command:

--------------------------
ocpidev show hdl libraries
--------------------------


only shows the available HDL libraries.

OPTIONS
-------
There are no options other then the options common to all OpenCPI tools
(see link:opencpi.1.html[opencpi(1)]),


EXAMPLES
--------
. List all components in any registered projects:
+
------------------------
ocpidev2 show components
------------------------
